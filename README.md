# 🐱 Cat Status API

A responsive and interactive web application that displays cat images based on HTTP status codes using the **HTTP Cats API**.

## 🚀 Features

- 🐱 Fetch cat images using HTTP status codes
- 🔍 Search and enter custom status codes
- 🎲 Generate random status codes
- 📋 Copy API endpoints to the clipboard
- ⬇️ Download cat images
- 🕘 View recently searched status codes
- ⏳ Loading indicators and error handling
- 📱 Responsive design for desktop and mobile

## 🛠️ Technologies Used

- HTML5
- CSS
- JavaScript 
- HTTP Cats API

## 🌐 API Used

**HTTP Cats API:** https://http.cat/

Example API endpoint:

`https://http.cat/404`

This displays a cat image representing the HTTP 404 Not Found status code.

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/cat-status-api.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter an HTTP status code and explore the cat images.
